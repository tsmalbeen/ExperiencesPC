Le Web : URL, HTTP et moteur de recherche

Une adresse web se lit morceau par morceau. Quand on clique sur un lien, le navigateur envoie une requête HTTP au serveur, qui répond avec un code et le fichier demandé. Un moteur de recherche, lui, a lu les pages à l'avance et les classe à partir de son index.

3. Un moteur de recherche miniature

    
Le moteur a parcouru les pages du petit site et noté, pour chaque mot, dans quelles pages il apparaît et combien de fois : c'est l'index. Les pages sont classées selon le nombre d'occurrences des mots cherchés, avec un bonus quand le mot est dans le titre.

    
    

      

      

    

  


  
Le petit site est simulé dans cette page : aucune requête ne part réellement sur le réseau. Un vrai moteur de recherche utilise bien d'autres critères, par exemple le nombre de liens qui pointent vers une page.
