Données structurées : une table de randonnées

Des données organisées en table : chaque ligne est un objet (une randonnée), chaque colonne un descripteur (sa distance, son dénivelé…). Enregistrées dans un simple fichier texte au format CSV, elles se trient, se filtrent et se résument en quelques clics.

—

Le même contenu, tel qu'il est écrit dans le fichier : une ligne par objet, les valeurs séparées par des virgules, la première ligne donne le nom des descripteurs. Modifie le texte : la table suit.
