Représentation des données : types construits

Les types construits regroupent plusieurs valeurs : le tableau (list en Python) est modifiable et indexé à partir de 0, le p-uplet (tuple) ne se modifie pas, le dictionnaire associe des clés à des valeurs. Chaque bouton exécute une instruction Python et montre son effet.

def min_max(t):
    """Renvoie le plus petit et le plus grand élément de t, sous forme de p-uplet."""
    return min(t), max(t)
