Interactions sur le Web : événements et formulaires

Dans le navigateur, chaque action de l'utilisateur déclenche un événement auquel un programme JavaScript peut réagir. Quand on valide un formulaire, ses données partent vers le serveur dans une requête HTTP, avec la méthode GET (dans l'adresse) ou POST (dans le corps de la requête).

      événement : element.addEventListener('click', fonction)
      GET : données dans l'URL, après le « ? »
      POST : données dans le corps de la requête
      HTTPS : requête chiffrée entre le navigateur et le serveur
    

  


  
Le serveur est simulé dans la page : rien n'est réellement envoyé. Avec GET, l'adresse complète reste dans l'historique du navigateur et dans les journaux du serveur : on ne l'utilise jamais pour un mot de passe.
