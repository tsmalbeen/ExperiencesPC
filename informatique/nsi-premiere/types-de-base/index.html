Représentation des données : types de base

Dans la mémoire d'un ordinateur, tout est suite de bits. Selon le type de la donnée, la même suite se lit comme un entier, un entier relatif, un nombre à virgule ou un texte. Clique sur les bits pour les changer, ou saisis une valeur pour voir son codage.

En Python, les entiers n'ont pas de taille limite : le langage ajoute des octets au besoin. Les tailles fixes (8, 16, 32 bits) montrées ici sont celles qu'utilisent le processeur et de nombreux autres langages.
