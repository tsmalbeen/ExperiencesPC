Portes logiques et machine de von Neumann

À la base de tout processeur, des portes logiques combinent des bits ; assemblées, elles savent additionner. Au niveau au-dessus, la machine de von Neumann range programme et données dans la même mémoire et répète sans fin le même cycle : charger une instruction, la décoder, l'exécuter.

Une ligne par case mémoire, à partir de l'adresse 0 : une instruction (LOAD 10) ou un nombre. Instructions : LOAD, STORE, ADD, SUB, JMP, JZ (saut si ACC = 0), JN (saut si ACC < 0), OUT, HALT.

ET : 1 si les deux entrées valent 1 OU : 1 si au moins une vaut 1 OU exclusif : 1 si elles sont différentes cycle : charger → décoder → exécuter
Machine volontairement minimale : 16 cases de mémoire, un seul registre de calcul (l'accumulateur). Chaque instruction est codée par un nombre : le chiffre des centaines indique l'opération, les deux derniers chiffres l'adresse concernée.
