Bases de données : requêtes SQL

La base d'une bibliothèque, en trois relations reliées par des clés étrangères. Écris des requêtes SQL pour interroger les données, les joindre, les regrouper, ou les modifier : le système de gestion vérifie au passage les contraintes d'intégrité.

Schéma relationnel

Souligné : clé primaire. En bleu : clé étrangère, qui doit correspondre à une clé primaire existante. Touche le nom d'une relation pour afficher son contenu.

Requête —

Écris une requête, ou choisis un exemple.

Exemples
SELECT colonnes FROM relation WHERE condition JOIN autre_relation ON clé_étrangère = clé_primaire ORDER BY, GROUP BY, COUNT, AVG, SUM, MIN, MAX INSERT INTO, UPDATE … SET, DELETE FROM
Moteur SQL simplifié, écrit dans la page et inspiré de SQLite : il couvre les requêtes du programme, mais pas tout le langage. Les livres et les auteurs sont réels ; les emprunts sont fictifs. Les modifications ne sont pas enregistrées : recharger la page rend la base d'origine.
