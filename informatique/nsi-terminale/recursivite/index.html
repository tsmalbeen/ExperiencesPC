Récursivité : pile d'appels, arbre d'appels, tours de Hanoï

À toi : touche une tige pour prendre son disque du dessus, puis une autre pour l'y poser. Jamais un disque sur un plus petit.

      

        
def hanoi(n, depart, arrivee, intermediaire):
    if n == 0:
        return
    hanoi(n - 1, depart, intermediaire, arrivee)
    print('disque', n, ':', depart, '→', arrivee)
    hanoi(n - 1, intermediaire, arrivee, depart)
